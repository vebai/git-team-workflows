# Starter project

A small project for independent Git practice. Commit and edit these files only in a copied, disposable repository.

Files: `README.md`, `config/app.yaml`, `docs/notes.md`, `.gitignore`.

Run from the top level of the Git Team Workflows repository:

```bash
bash scripts/new-practice-repo.sh sample-one
git -C practice/sample-one status
git -C practice/sample-one log -1 --oneline
```
