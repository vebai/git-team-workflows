# Contributing to the practice project

1. Start from the current `main` branch.
2. Create a small feature branch with an informative name.
3. Commit one logical change with a descriptive message.
4. Inspect `git diff` and `git status` before sharing the branch.
5. Open a PR/MR describing the change and the evidence used to verify it.
6. Address review feedback on the feature branch.
7. Integrate only after the required checks and reviews are satisfied.

This is a **practice** contribution guide. Follow the real policy of any repository you contribute to.
